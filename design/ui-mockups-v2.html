The system

True black ground, a four-step grey ramp for surfaces, white text. White is the primary action — the FAB, the Save button, the selected filter. Emerald appears only for positive amounts, the confirm action, and the active tab indicator. Everything else is grey on grey.

Color as data

Category color is a 7px dot — never a tile fill, never a pill background, never a gradient. The donut chart is the one place color carries area, because there it's literally proportion. This is what stops it looking like a vibe-coded app: color has a job, and it does only that job.

What's new

Floating + button on Home for instant manual entry. Full edit screen behind every transaction — amount, merchant, and category are all tappable, plus an optional notes box. The add sheet has a notes field too. Date and reference stay read-only (they're facts, not opinions).

Why optional notes

Notes are never required. Most transactions need none. But "dinner with Priya" or "office cab" turns a row of ₹90 debits into something you can actually remember three months later. The field is there when you want it, invisible when you don't.
