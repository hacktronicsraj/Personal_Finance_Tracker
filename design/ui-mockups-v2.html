What changed

Floating + button on Home for instant manual entry. Full edit screen behind every transaction — amount, merchant, and category are all tappable, plus an optional notes box. The add sheet now has a notes field too. Date and reference stay read-only (they're facts, not opinions).

What stayed

True #000 AMOLED ground, one indigo accent, category color only as data. The lock-screen notification is still the signature moment. Activity feed, Insights donut, and the tab bar are structurally the same — they already worked. No redesign for redesign's sake.

Notes — why optional

Notes are never required. Most transactions need none. But "dinner with Priya" or "office cab" turns a row of ₹90 debits into something you can actually remember three months later. The field is there when you want it, invisible when you don't.

Edit, don't re-enter

The old detail screen was read-only except for category. Now a wrong amount, a misread merchant, or a missing note is a one-tap fix — tap the pencil, edit inline, save. Delete is a deliberate separate button so you can't lose a row by accident.
