05 · The month in shape

Insights

Donut for proportion, ranked merchant bars for habit-spotting. Swipe months to compare.

Color system

True #000 screens (AMOLED-friendly, battery-cheap), surfaces one step up at #0E0F13 with hairline borders instead of shadows. A single indigo accent #7C83FF marks everything interactive; the ten category hues appear only as data — tiles, bars, donut slices — never as decoration.

Type & numbers

System grotesk (Roboto on device) so it feels native. Money is the display type: heavy weight, tight tracking, tabular numerals so amounts align in every list, with the ₹ sign picked out in accent. Mono microcaps for metadata like SYNCED · 21:47.

Signature moment

The lock-screen notification is the product: pay → guess → one-tap confirm. Low-confidence guesses get an amber "needs review" trail through Dashboard and Activity, so nothing stays misfiled longer than a glance.
